##HTML·CSS
#TAG 
#문서 (구조태그)
<head> (문서 정보 영역)

웹페이지의 메타데이터(제목, 설정을 나타내는 정보, CSS 스타일시트 연결 등)를 담는 영역입니다.

이 안에 작성된 내용은 웹브라우저의 화면에 직접 노출되지 않습니다.
<body> (문서 본문 영역)

웹브라우저 화면에 실제 표시되는 모든 콘텐츠(텍스트, 이미지, 버튼 등)가 들어가는 영역입니다.
#Text & Paragraph (텍스트 및 문단 태그)
<p> (Paragraph / 문단)

하나의 독립된 텍스트 문단을 정의할 때 사용합니다.

태그 위아래에 기본적으로 약간의 여백(Margin)이 자동으로 생성되는 블록(Block) 요소입니다.
#List (목록 태그)
<ul> (Unordered List / 순서 없는 목록)

순서가 중요하지 않은 항목들의 목록을 만들 때 사용합니다.

기본적으로 각 항목 앞에 작은 불릿 기호(•)가 붙습니다. (하위 요소로 <li> 태그를 사용함)

<ol> (Ordered List / 순서 있는 목록)

순서나 번호가 중요한 항목들의 목록을 만들 때 사용합니다.

항목 앞에 숫자(1, 2, 3...)나 알파벳 등의 순서가 자동으로 붙습니다. (하위 요소로 <li> 태그를 사용함)
# Input & Media (입력 및 미디어 태그)
<input> (사용자 입력 양식)

사용자로부터 텍스트 입력, 체크박스 선택, 날짜 지정 등 다양한 입력을 받을 수 있는 양식 요소입니다.

type 속성에 따라 모양과 기능이 달라집니다. (예: type="text", type="password", type="checkbox")

닫는 태그가 없는 단일 태그(Self-closing tag)입니다.

<img> (Image / 이미지 삽입)

웹페이지에 이미지 파일(.jpg, .png, .gif 등)을 보여줄 때 사용합니다.

주요 속성으로 이미지 경로를 지정하는 src="경로"와 이미지를 불러오지 못했을 때 대체 텍스트를 제공하는 alt="설명"을 필수적으로 사용합니다.

닫는 태그가 없는 단일 태그입니다.
